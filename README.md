# QodeMe - Programming MCQs Platform

**Project Status: In Progress**

This project aims to provide programming Multiple Choice Questions (MCQs) for users to answer and improve their coding skills. All questions are generated by ChatGPT.

## Supported Languages

- **Java** - Object-oriented programming questions
- **JavaScript** - Web development and scripting questions  
- **Python** - General programming and data science questions

## Features (Coming Soon)
- Interactive MCQ interface
- Score tracking and progress monitoring
- Questions categorized by difficulty level
- Detailed explanations for answers
- User authentication and profiles

## Tech Stack

- **Frontend:** Next.js, TypeScript, JavaScript, HTML/CSS, TailwindCSS
- **Backend:** Node.js
- **Database:** PostgreSQL
- **Data Format:** JSON
- **AI:** ChatGPT (for question generation)

## Getting Started
First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
